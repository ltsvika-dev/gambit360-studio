# Gambit360 Studio – קוד המקור

הקובץ `Gambit360 Studio.html` שבתיקייה מעל נבנה מהחלקים שבתיקייה הזו. הוא נשאר קובץ אחד, בדיוק כמו קודם, וייצוא חבילת לקוח ממשיך לקרוא אותו כרגיל.

- `Gambit360 Studio.src.html` – שלד הדף. כל שורה `@@include(...)@@` מוחלפת בתוכן הקובץ שהיא מציינת.
- `css/` – העיצוב של הסטודיו.
- `html/body.html` – המבנה של המסך.
- `js/10-translations.js` – כל הטקסטים בעברית ובאנגלית.
- `js/11-e57-reader.js` – קריאת קבצי E57.
- `js/20-viewer/` – הצפיין עצמו, קובץ לכל נושא (חבילת לקוח, פרויקט, ענן נקודות, תגיות, צילום, סרטון פרומו, מיני מפה, תכניות PDF, מדידות).
  הקבצים כאן הם המשך של בלוק אחד, ולכן הם לא עומדים בפני עצמם. הסדר נקבע לפי המספר.
- `js/3x-*.js` – תפריט האפשרויות, תנאי שימוש, נגישות, גרסה ועדכוני לקוח.
- `js/34-side-columns.js` ו-`css/side-columns.css` (Studio בלבד) – הפס העליון עם הלשוניות "ענני נקודות" / "סיורים חיים", ושתי העמודות מימין בענני נקודות (נקודות עניין, חבילה ללקוח, תכניות קומה). רוחב התצוגה התלת־ממדית הוא `VW()` (ב-`20-viewer/00-core.js`), ולא `innerWidth`.
- `live-tours/` – מודול "סיורים חיים" (Studio בלבד): העיצוב, המסך, הדף שמתפרסם לשרת, upload.php והקוד.
  - `live-tours/upload.php` הוא רק הראש של הקובץ; שאר החלקים ב-`live-tours/upload/` (דוחות במייל, הסטודיו אונליין, קישורי הדוחות, כניסה, ענן ועדכון עצמי, סיורים וסטטיסטיקה, העלאת קבצים). הבנייה מחברת אותם לקובץ אחד, והסטודיו מעלה אותו כרגיל.
  - `live-tours/card.js` ו-`card.css` – כרטיס הפרטים של הסיור. גם הדף המפורסם וגם התצוגה המקדימה כוללים אותם, ולכן שינוי בכרטיס נעשה רק שם.
  - שדה חדש בסיור: ברירת המחדל שלו נכנסת רק ל-`TOUR_DEF` ב-`live-tours/js/01-storage.js`. סיור חדש וסיור ישן מקבלים אותה משם.

## בנייה
`build.bat` (או `python build.py`) כותב את `..\Gambit360 Studio.html`.
`python build.py --check "..\Gambit360 Studio.html"` רק בודק שהקובץ תואם לחלקים.
`python check.py` בודק שה-HTML תואם לחלקים ושאין שגיאות תחביר ב-JavaScript וב-PHP (אם Node.js ו-PHP מותקנים). ‏`build.bat` מריץ אותו אחרי הבנייה.
בדיקות בדפדפן: `tests/` (ראו README שם). ב-GitHub שתי הבדיקות רצות לבד בכל שינוי.

הסימונים `/*@STUDIO*/ ... /*@/STUDIO*/` ו-`<!--@STUDIO--> ... <!--@/STUDIO-->` נשארים כמו שהם: ייצוא חבילת לקוח מסיר את מה שביניהם.
