# בדיקות בדפדפן

`run.mjs` פותח את `Gambit360 Studio.html` הבנוי בדפדפן אמיתי (Chromium דרך Playwright), עם שרת PHP מקומי שמחקה את האתר של הסיורים, ובודק:

1. סיור שנוצר בגרסה ישנה של הסטודיו (`fixtures/old-tour.json`) נפתח, כל הסקשנים בעורך נפתחים, ואין שגיאות.
2. סיור חדש נשמר עם כל השדות מההתחלה.
3. פרסום מעלה את הסיור לאתר המקומי, וכרטיס הפרטים בדף המפורסם זהה לכרטיס בתצוגה המקדימה.
4. מחשב שני עם אותו מפתח מקבל את הסיור מהשרת (ענן).

## הרצה
צריך Node.js ו-PHP. בתיקייה הזו:

```
npm install
npx playwright install chromium
npm test
```

`npm test -- "path\to\Gambit360 Studio.html"` בודק קובץ אחר (למשל גרסה ישנה, כדי לראות שהבדיקה תופסת תקלה).
three.js נלקח מ-`lib/` שליד ה-HTML; אם אין, הוא יורד פעם אחת מ-npm לתיקייה `.cache`.

ב-GitHub הבדיקות האלה רצות לבד בכל שינוי, יחד עם `src/check.py`.
